# Community

DBZ LSW Fangame uses different channels for different kinds of participation so that research, bug reports and general conversation do not become mixed together.

## Official public channels

### GitHub

Repository: https://github.com/smouj/dbzlsw-fangame

Use GitHub for work that should become part of the project:

- **Issues** — reproducible bugs, ROM-fidelity discrepancies, research proposals and scoped feature requests.
- **Pull requests** — code, tests, documentation and reviewed derived data.
- **Actions** — public CI and source-safety status.

### Reddit

Community: https://www.reddit.com/r/DBZ_LSW_FANGAME/

Use Reddit for:

- development updates
- screenshots and progress posts
- broader community discussion
- feedback that does not yet have a reproducible technical scope

A public development preview has also been posted to r/IndieGames:
https://www.reddit.com/r/indiegames/comments/1vpzm0h/i_am_recreating_dragon_ball_z_legendary_super/

### X / Twitter

No X account is linked from the project until the maintainer confirms an exact official handle. Do not infer an official account from a similar display name and do not add an unverified profile to README, releases or social metadata.

When an official handle is confirmed, update this file, `README.md` and `docs/BRANDING.md` in the same pull request.

## Where should I post something?

| You have... | Use... |
|---|---|
| A reproducible game bug | GitHub bug issue |
| Evidence the GBC behaves differently | GitHub ROM-fidelity issue |
| A code/documentation fix | Pull request |
| A question about contributing | GitHub issue/discussion when enabled |
| A screenshot or progress reaction | Reddit |
| A speculative research lead | Research issue, clearly marked as hypothesis |
| A security concern | Follow `SECURITY.md`; do not post exploit details publicly |

## Community standard

Technical disagreement is expected; personal hostility is not. Challenge evidence, assumptions and implementations rather than contributors. See `CODE_OF_CONDUCT.md`.

## No unofficial support claims

Forks and community builds are welcome under the applicable licenses, but they must not present themselves as an official build or official social channel unless the maintainers explicitly designate them as such.
