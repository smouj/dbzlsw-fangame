# Project Branding and Repository Metadata

## Canonical public name

**DBZ LSW Fangame**

Repository slug: `dbzlsw-fangame`

The public name intentionally avoids `remake` and `online`. `Fangame` matches the community identity while clearly communicating the unofficial project scope.

## Short description

Recommended GitHub description:

> Open-source, research-driven fangame recreation of Dragon Ball Z: Legendary Super Warriors (GBC), focused on deterministic combat and ROM-backed fidelity.

## Long description

> DBZ LSW Fangame is a community-driven, non-commercial recreation of Dragon Ball Z: Legendary Super Warriors for modern systems. Development emphasizes reproducible GBC research, deterministic gameplay, physical animation provenance and faithful battle presentation rather than undocumented approximation.
