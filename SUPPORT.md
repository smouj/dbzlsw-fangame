# Support

Use GitHub Issues for reproducible project problems and GitHub Discussions if/when enabled for broader questions and community conversation.

Before opening an issue:

- search existing issues
- identify the exact revision or build
- include reproduction steps
- distinguish a gameplay bug from a ROM-fidelity discrepancy
- include evidence when claiming the original GBC game behaves differently

This is a volunteer, non-commercial fan project. There is no guaranteed response time or end-user support SLA.
